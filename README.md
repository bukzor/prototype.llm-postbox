# agent-harness

A mechanism by which one agent creates, constrains, observes, converses
with, and judges other agents, designed for one person's claude-code
sessions. Delegates are ordinary sessions. Output is offered, never
forced. Acceptance rests on artifacts, never on a delegate's own
report.

Its conversation channel is the postbox: a message is a markdown file
in the recipient's inbox, delivery is a read at a task boundary, and
the sender can see, edit, or retract mail until it is read.

Design only, nothing implemented. Start at
[docs/dev/claims.kb/design.md](docs/dev/claims.kb/design.md).
