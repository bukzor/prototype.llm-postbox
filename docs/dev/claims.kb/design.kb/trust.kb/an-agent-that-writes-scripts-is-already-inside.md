# An agent that writes scripts is already inside

An agent permitted to write scripts and run Bash is already inside
whatever a permission rule rests on. It can edit the script that
marks its own output, propose the allowlist meant to bound it, and
rewrite the hook that checks it — each by ordinary use of the tools it
was granted.

The trust was therefore extended at the grant of those tools, not at
any mechanism downstream of the grant, and nothing downstream can
withdraw what the grant already gave.
