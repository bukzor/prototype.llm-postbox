# An empty payload bounds what a broken convention can cost

Convention-dependent mechanisms differ in what a failure of the
convention carries. Where the payload is empty — a nudge saying only
that mail exists — a failure costs a session one look at a postbox
that held nothing for it. Where the payload carries content, a failure
costs whatever the content was, and the content is unbounded.

This is the measure to apply whenever a mechanism is challenged for
resting on self-restraint: price the omission, not the reliance.
