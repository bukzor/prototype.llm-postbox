# The owner is the only boundary the agent cannot reach around

Given FOOLPROOFING, the mechanisms worth spending on are the ones
that route through the owner's attention: SEND_GATED's Ask prompt,
which shows a cross-scope message as a diff before it is written, and
the wake keybinding the owner presses. They hold because the agent is
not the one enforcing them.

Everything the agent imposes on itself — a wrapper it can edit, an
allowlist it can propose, a marker it can omit — bounds mistakes
only, and pricing it higher buys false confidence. Put what must not
go wrong at a point the owner passes through, and keep the rest
cheap.
