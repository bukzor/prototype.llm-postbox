# Marking agent-authored text where a from-header cannot reach

Text one session sends into another arrives as a user turn. The
transport carries no from-header, so nothing in the message itself
distinguishes the owner's words from an agent's, and the recipient
supplies the owner's authority by default. This theory fixes a marker
that says otherwise in the body, and coins the two words its reasoning
turns on: a *privilege drop*, which is what the marker does to what
follows it, and *capture*, which is how far that reaches.

`callout` is deliberately not on that list. BROUGHT_WORD is the claim
that it is already every agent's word, and a theory that owned it
would be policing ambient vocabulary rather than stipulating anything.

The marker is a guard in TRUST's sense and nothing more. That it can
be omitted by an agent that wants to is not an objection
(CONVENTION_PARITY), and what makes the omission cheap is
BLAST_RADIUS.
