# postbox.kb -- where a new file goes

The postbox component, kept as a claim ledger (`Skill(llm-claims-kb)`).
`../postbox.md` is the defining claim.

- A mechanic of the mailbox itself, in root vocabulary -> here, beside
  the theory files.
- A claim arguing in a theory's vocabulary -> that theory's `.kb/`:
  `topology.kb/` for the shape on disk, `live.kb/` for waking a
  session, `marking.kb/` for attributing agent-authored text.
- A declined candidate -> beside the claim that beat it, with
  `verdict:`, so `ls` enumerates a decision's answers.
- A property of the channel that any mailbox would have to satisfy ->
  not here: `../../goals.kb/delivery.kb/` or `../../goals.kb/trust.kb/`.
- Implementation tasks -> `.claude/todo.md` at the repo root.
