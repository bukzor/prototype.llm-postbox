# Drafts restore the pre-read window

In closed loops the pre-read window collapses to seconds, degrading
MUTABLE_UNTIL_READ to post-hoc audit. The opt-in restoration: mail
composed as `*.draft.md` is invisible to readers and promoted by
rename — by the owner, or by an orchestrator for pre-approved traffic
classes. Routine mail skips the stage.
