# Making the marking hold without anyone remembering it

A convention carried by the sender's memory fails whenever memory
does. That is not disqualifying (CONVENTION_PARITY) and it is cheap
here (BLAST_RADIUS) — but it is also removable, and this theory is how
it gets removed.

The word it coins is *wrapper*: the single command an agent is
permitted to send with, which writes the marker itself so that no
sender ever types it. What the wrapper cannot do is bind an agent that
means to go around it; it is a guard, and CONSTRUCTION states exactly
how much a guard can be asked for.
