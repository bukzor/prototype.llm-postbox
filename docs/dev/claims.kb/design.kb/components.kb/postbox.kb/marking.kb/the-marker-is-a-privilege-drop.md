# The marker is a privilege drop

Text the marker covers is taken with less authority than unmarked
text, never more. It says "an agent wrote this", which is strictly
weaker than the user turn the text physically arrives in, and no
marker in this family raises what it covers.

That direction is the whole design. A mechanism that could elevate
text would have to be tamper-proof to be worth anything; one that can
only lower it has nothing an attacker would want.
