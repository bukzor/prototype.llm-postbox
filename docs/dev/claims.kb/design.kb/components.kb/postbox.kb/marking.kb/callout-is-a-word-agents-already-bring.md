# `callout` is a word agents already bring

The element is named `callout` because that is already GitHub's and
Obsidian's presentation word for the construct. An agent meeting
`<callout tag="@claude"/>` needs no gloss to know roughly what it
means.

A coined synonym would be more precise and would have to be taught,
and a convention that must be taught before it can be read fails
silently wherever the teaching did not reach. This is also why MARKING
does not own the word: there is nothing here to stipulate.
