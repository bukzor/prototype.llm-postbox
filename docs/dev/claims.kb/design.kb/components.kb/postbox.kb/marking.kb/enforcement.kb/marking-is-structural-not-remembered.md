# Marking is structural, not remembered

With the wrapper writing the marker (WRAPPER_MARKS) and the unwrapped
path gated (WRAPPER_ONLY), sending unmarked text requires working
around the design rather than merely forgetting it.

That is the whole of what a guard can be asked for. It does not stop
an agent that means to (FOOLPROOFING), and it does remove the failure
that actually happens — which is the trade this design makes
everywhere.
