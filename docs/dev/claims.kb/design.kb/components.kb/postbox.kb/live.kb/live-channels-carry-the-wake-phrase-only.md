# A live channel carries the fixed wake phrase, nothing else

A wake ping — resume, keybinding, any live channel — is the fixed
formulaic phrase "check your postbox". Two premises settle it: content
in a live channel is unreviewable and unretractable the instant it is
sent (MUTABLE_UNTIL_READ), and it arrives in the owner's own voice
(WAKE_WEARS_AUTHORITY). The fixed phrase carries neither content nor
judgment, so both hazards vanish; the message itself waits in the
postbox, still the sender's.
