# A message enters a delegate's context only at a moment the delegate chose

A message sent to a delegate mid-work enters its context only when
the delegate itself reads, or at a moment the delegate armed in
advance. Probe: send while the delegate is inside a long tool run and
diff its transcript afterward; the message appears after the
delegate's own read and nowhere earlier. Both candidate channels face
this probe, and neither has run it.

The lived failure this answers is the second of PUSH_GROUNDS,
recipient distraction.
