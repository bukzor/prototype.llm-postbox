# The per-job fixed cost is measured, and a job needing no convention pays none

The per-job fixed cost, meaning what a job pays before doing any work
(system prompt, ambient instructions, bootstrap reads), is measured and
stated. A job requiring no ambient convention does not pay for any.

The number itself is deferred to the first measured run; the method
is already in hand, since HOOK_NOISE priced one ambient cost from
transcripts alone. It is the same
concern as a clean working directory (CONFINE) seen from the cost side.
