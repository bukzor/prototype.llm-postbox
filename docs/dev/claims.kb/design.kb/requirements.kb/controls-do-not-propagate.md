# A control from one delegator does not reach the other

An interrupt or message from the person to a delegate neither stops nor
notifies the orchestrating agent, and an interrupt or message from the
orchestrator neither stops nor notifies the person.

The lived failure this answers is STOP_PROPAGATES.
