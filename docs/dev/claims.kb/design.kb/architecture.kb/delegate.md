# What is a delegate, on this substrate?

Settled: an ordinary session (IS_SESSION). `delegate.kb/` holds the
three answers: the session, chosen; the built-in agent tool, vetoed by
the owner on 2026-08-28 with no revisit condition (AGENTS_INTERFACE);
and a bespoke harness, declined because it would re-pay every
capability a session already has (BESPOKE_HARNESS).

The choice cost nothing the vetoed answer had. Its measured win is
three properties, lean context, a cheaper model, and artifact
quarantine, and a session collects all three; what the session has
that the tool never did is PARITY. Reopens only if the owner lifts the
veto.
