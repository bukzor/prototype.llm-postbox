# A bespoke harness as the delegate

A delegate runtime of its own, re-implementing each session capability
the design needs: start, resume, interrupt, rewind, record.

Declined: it would re-pay every capability the session already has and
still miss the next one the person reaches for, which is PARITY read
as a cost.
