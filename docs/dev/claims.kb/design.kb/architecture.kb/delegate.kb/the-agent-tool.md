# The `claude agents` / Agent-tool interface as the worker channel

The ground is the interface, not the economics: the measured
subagent win is three properties — lean context, a cheaper carrier
model, artifact quarantine — and any transport with those properties
collects it: tmux worker windows with `/clear` discipline, `claude -p`
one-shots, postbox workers. What the interface never had, the
replacements keep — workers as real terminals, watchable,
interruptible, surviving the driver.
