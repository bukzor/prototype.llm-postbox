# Four reasons to delegate

A delegator delegates for four reasons: a cheaper agent, parallel
wall-clock, work exceeding one context, and a reading free of the
delegator's own assumptions. The mechanism serves all four.

- a cheaper agent can do the work;
- parallel work saves wall-clock;
- the work exceeds what fits in one context;
- a reading is wanted that the delegator's own assumptions did not
  produce.

Declined: the earlier draft admitted only the last two and called them
the only two. The first two are the reasons the person's agent roster
is built around, and they spend currencies the exchange rate must count
(EXCHANGE).
