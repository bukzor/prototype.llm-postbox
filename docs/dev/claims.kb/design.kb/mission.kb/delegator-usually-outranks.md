# The delegator usually outranks the delegate, and sometimes does not

The delegator is usually the more capable agent, dispatching routine
work downward. Sometimes it is the less capable one, calling a
higher-grade agent for a single judgment. Both directions are ordinary
delegations: in the second, the delegate is given access and a spec for
the judgment wanted, and the judgment it writes is its result.

What rank changes is how much access the delegate needs and what the
delegator can check about the result; one mechanism covers both
(ONE_MECHANISM).
