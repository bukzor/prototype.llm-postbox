# Delegator and delegate name a position, not a kind of session

Since either party may start a session and hands may change (STARTER),
*delegator* and *delegate* name the position a session holds at a
moment rather than a kind of session it is. One session is a delegator
with respect to what it sends and a delegate with respect to
the one it receives.

The design has one kind of participant, so every claim that names a
role is naming a position in an exchange. The postbox's older claims
say *worker*, *orchestrator*, and *driver* for the same positions.
