# A callout is a blockquote carrying a type marker

Both dialects this convention has to survive spell a callout the same
way: a blockquote whose first line is a bracketed type, `> [!NOTE]`.
Obsidian calls them callouts and GitHub calls them alerts; the syntax
and the block-level shape are the same in each.
