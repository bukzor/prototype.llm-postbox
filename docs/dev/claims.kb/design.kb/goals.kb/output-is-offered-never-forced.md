# Output is offered, never forced

Every output a job produces is optional to read. Dispatch is one small
bounded act. Results land at an address and stay there until asked for.
Progress and completion are observable without polling. Many jobs cost
little more attention than one.

Prevents: attention flood, where results return in a form that must be
read, so delegating costs more than doing. The lived instance is
FORCED_OUTPUT.

There is no exception for the person: what they want to see, they ask
for, and a delegate blocked on a question only they can answer reaches
them by the conversation channel (CONVERSE), never by forcing its
result.
