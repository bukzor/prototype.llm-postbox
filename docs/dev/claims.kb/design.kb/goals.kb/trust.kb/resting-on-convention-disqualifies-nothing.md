# Resting on convention disqualifies nothing

A mechanism that holds only while senders keep to a convention is not
disqualified by that fact, because the mechanisms this design has
already accepted hold the same way. Whatever an agent sends arrives in
the human's voice, and what keeps a recipient from reading it as the
owner's instruction is convention alone.

So "an agent could simply omit it" is no objection by itself — it is
equally true of the plan of record. The admissible question is what
the omission costs (BLAST_RADIUS), never whether self-restraint is
load-bearing; here, it always is.
