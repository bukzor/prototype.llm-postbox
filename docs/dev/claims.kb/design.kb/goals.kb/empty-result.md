# A job's result may be empty

Proposed on 2026-09-01: a higher-grade agent joining a session as a
participant produces conversation rather than an artifact, so the
mechanism should allow a job's result to be empty and acceptance to
rest on the conversation.

Rejected. A judgment written against a spec is an artifact, so the
participant case has a result like any other; an empty result would be
wanted only where side effects were the whole point, which the person
judges unlikely. The proposal came from reading "participant" as "joins
the chat" and weakening EVIDENCE to fit; the fix was to read it as
"called with a spec". Kept here so the idea is not re-proposed.
