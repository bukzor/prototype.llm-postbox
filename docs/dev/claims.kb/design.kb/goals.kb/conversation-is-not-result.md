# Each delegator can converse with a running delegate

Each delegator can reach a running delegate and be reached by it. This
conversation channel is distinct from the result channel, so a
conversation never silently becomes an artifact, nor an artifact a
conversation. Neither direction spins.

A delegate that needs a decision only its delegator can make asks by
this channel; the answer arrives by it; the record keeps the exchange
apart from the result.

Prevents: a delegate wedged on a question it cannot ask, and a
conversation mistaken downstream for a deliverable.
