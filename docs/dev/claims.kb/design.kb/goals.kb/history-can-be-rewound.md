# A delegate's history can be rewound

A delegator can discard a delegate's most recent turns and continue it
from the earlier state, as the person can in a session.

Neither re-run nor resume covers this: re-run starts over, resume
continues from the end. The lived instance is NO_REWIND, and history
rollback is on the person's list of what a delegate lacks.

Agent-signed: the person named rollback as missing and did not rule on
it as a goal; veto if rewind is not worth its place.
