# A delegate lacks no capability the person has in a session

A delegate lacks no capability the person has in a session.

This is derived, not stipulated, at the person's request:

1. Every session capability a delegate lacks is one the delegator pays
   for in attention when it is needed: a workaround, a re-dispatch, a
   lost run. That is a term in the attention rate (EXCHANGE).
2. The lived failures show the person needs nearly all of them: six of
   ten are exactly such capabilities (DEGRADED), and their absence is
   why delegation is avoided at all (AVOIDS).
3. LIFECYCLE already demands the ones that cost most when missing:
   resume, interrupt, survive a restart.
4. So the exchange rate is best when no capability is absent, and any
   enumeration of "the ones a delegate does need" would be re-derived
   every time a new one turned out to be missing.

Stands bare: accepting the premises settles it. The residue a skeptic
would raise, that a capability the person never uses costs nothing
missing, is answered by step 2; the list is nearly the whole set.

Declined: an enumerated subset of session capabilities.
