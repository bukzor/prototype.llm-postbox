# Goals

**How do we accomplish the mission?**

By a mechanism with the properties in `goals.kb/`. Each property is
stated as what must be true, never how it is achieved; each names the
failure it prevents.

Words this rung stipulates:

- a **job** is one unit of delegated work, dispatched once, and a value
  in its own right;
- a job's **reach** is what it may read, write, run, fetch, send, and
  delegate;
- a job's **record** is what something other than the delegate writes
  down about it;
- an **artifact** is what a job produces at an address, as distinct from
  what it claims about itself;
- a **channel** is a path by which a delegator and a running delegate
  exchange messages, distinct from the path by which artifacts return.

The mechanism is good exactly as far as it improves an exchange rate
(EXCHANGE); every other goal here is a way of improving one of its
terms.
