# Derive the shape from the problem, never from an incumbent

The shape is derived from the mission, goals, and requirements. An
existing mechanism is examined only after those are settled, and then
as evidence of what the substrate can do, never as a baseline to
increment. An incumbent read early becomes the design by default.

The person's testimony about an incumbent's failures (`experience.kb/`)
is admissible at any time: it is evidence of which problems are worth
solving, not a reading of the incumbent's design.
